# XL Research Framework - Ethics & Usage Policy

## Intended Use

This framework is designed for **legitimate security research and auditing purposes only**.

## Allowed Use Cases

- Security auditing of applications you own or have permission to analyze
- Academic research on mobile application security
- Defensive security analysis
- Learning about Android application architecture

## Prohibited Use

- Analyzing applications without authorization
- Creating tools for bypassing security mechanisms
- Developing exploits or malware
- Any illegal activities

## Disclaimer

Users are responsible for ensuring they have proper authorization before analyzing any application.
